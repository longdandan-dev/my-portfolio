# my-portfolio

我的第一个vite工程——前端学习阶段0 模块5 的产出，后续会在这里搭建作品集官网

## 怎么跑起来
```powershell
npm install
npm run dev
```
然后打开终端里显示的网址（默认 http://localhost:5173）.

## 目录说明
- `index.html`：页面入口
- `src/main.js`：JS入口
- `src/style.css`：样式
- `public`：原样拷贝的静态文件

## 用到的命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器（带热更新） |
| `npm run build` | 打包出 dist/ |
| `npm run preview` | 预览打包结果 |
